# Змейка

Классическая змейка на HTML5 Canvas. Работает без сборки и зависимостей — достаточно открыть `index.html`.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | `←` `↑` `↓` `→` или `WASD` |
| Пауза | `Пробел`, `Esc`, `P` |
| Новая игра | `Enter` (на оверлее) или `R` |
| Звук | `M` |
| Свайп | на телефоне — по полю |

Счёт: +10 за каждую сферу. Скорость постепенно растёт, рекорд хранится в `localStorage`.

## Структура

```
index.html        каркас страницы и HUD
css/style.css     оформление интерфейса
js/engine.js      платформа: цикл, ввод, свайпы, звук, canvas, хранилище
js/snake.js       игра: логика змейки, еда, частицы, отрисовка
js/main.js        связка платформы, игры и интерфейса
```

### Слой платформы (`engine.js`)

- `Loop` — `requestAnimationFrame` с фиксированным шагом 60 Гц и ограничением «догоняющих» кадров.
- `Input` — подписка на действия (`up`, `down`, `pause`, `restart`...), а не на конкретные клавиши.
- `Swipe` — свайпы через pointer-события.
- `Sfx` — короткие синтезированные звуки на Web Audio, состояние хранится в `localStorage`.
- `Stage` — canvas с учётом `devicePixelRatio` и `ResizeObserver`; сообщает игре о смене размера.
- `Storage` — безопасная обёртка над `localStorage`.

Игра (`snake.js`) не трогает DOM: получает сцену и колбэки `onScore` / `onState`, поэтому её легко переиспользовать или заменить.

## Настройки

Параметры поля и скорость — в `CONFIG` в начале `js/snake.js`:

```js
const CONFIG = {
  cols: 21,
  rows: 21,
  startLength: 4,
  baseStep: 150,
  minStep: 75,
  speedUpPerFood: 3,
  pointsPerFood: 10,
};
```
